# EDA не-новостных источников

**EDA новостного корпуса на этой машине:**
[`reports/news/news_eda.html`](reports/news/news_eda.html) — самостоятельный отчёт с
встроенными графиками; [`08_news_corpus`](notebooks/08_news_corpus.ipynb) — выполненный
ноутбук. Он анализирует локальную многоязычную выгрузку из `data/{raw,interim,processed}/news`,
а не старый русский датасет из `jup_files/data/02_news_eda.ipynb`.

```bash
# Из корня репозитория; без сети, скачивания статей, GPU и платной разметки
MPLCONFIGDIR=/tmp/oil-news-matplotlib .venv/bin/python eda/news_eda.py
# Перестроить отчёт по уже рассчитанным таблицам
MPLCONFIGDIR=/tmp/oil-news-matplotlib .venv/bin/python eda/news_eda.py --cached
```

Код: `news_eda.py`; таблицы, манифест входных файлов и CSV для ручной проверки:
`eda/data/derived/news/`. Данные там исключены из Git. Отчёт, рисунки и ноутбук
сохраняются в репозитории. Никакие исходные данные и файлы загрузчика не меняются.
Не начатые загрузки текстов отличаются от неудачных попыток; отсутствие попытки
остаётся пропуском, а не нулём новостей. Текстовые темы и кандидаты событий —
проверяемые словарные признаки, без заявления об измеренной точности извлечения.
Для привязки к релизам нужна распакованная папка `eda/data/processed/` из
`processed.zip` (команда распаковки ниже). Обновление кэша таблиц — обычный
запуск без `--cached`; этот флаг сам по себе не пересчитывает EDA после изменения кода.

---

Разведочный анализ данных из `processed.zip`: EIA, консенсус и API, фьючерсы WTI, FRED и
инфраструктура. Цель — понять таргет (inventory surprise), реакцию календарного спрэда и что из
данных можно честно использовать как признаки до релиза EIA.

## Как запустить

```bash
# из корня репозитория
unzip -q processed.zip 'processed/*' -x '*/.DS_Store' -d eda/data
cd eda/notebooks
uv run jupyter nbconvert --to notebook --execute --inplace 0*.ipynb   # по порядку 01 → 07
```

`eda/data/` в `.gitignore`. Ноутбук 04 пишет `eda/data/derived/curve_clean.parquet` (кривая с
разметкой роллов), 07 читает его и пишет `eda/data/derived/weekly_frame.parquet`, поэтому 04
запускается раньше 07. Общие пути, стиль графиков и таблица таргета — в `eda_utils.py`.
Разбиение по времени во всех ноутбуках: train — релизы до 2022-12-31, test — с 2023-01-01.

| Ноутбук | О чём |

## Главное

1. **Сюрприз почти не предсказуем по истории EIA.** Среднее +0.34 млн барр. (p = 0.078), толстые
   хвосты (эксцесс 1.8), без автокорреляции и без значимой сезонности. Модель на истории EIA на test
   не лучше нулевого прогноза (MAE 3.66 против 3.67, ноутбук 03); в 02 лучший лаговый набор даёт
   corr 0.20 прогноза-минус-консенсус с сюрпризом — слабо и на одном разбиении.
2. **`API − консенсус` — самый сильный признак.** Объясняет 51% дисперсии сюрприза, угадывает знак
   в 73.5% недель, ρ = 0.65–0.75 во всех периодах. API выходит во вторник в 16:30 ET, до EIA, —
   признак легальный. Поэтому прирост от новостей (M3, M5) надо мерить против базовой модели с API.
3. **Консенсус слабый и теряет информативность.** R² = 0.23; корреляция с фактом 0.64–0.71 в 2015
   и 2017, 0.35–0.39 в 2023–2026. На test он ненамного лучше сезонного среднего (MAE 3.67 против
   3.98) и заметно опирается на прошлую неделю (ρ с прошлым фактом 0.61).
4. **Спрэд F1−F2 на дневных закрытиях на сюрприз не реагирует.** Наклон −0.0016 $ на 1 млн барр.
   (p = 0.35, R² = 0.0005); направление верное в 55% релизов (p = 0.015), но величина ничтожна.
   Цена F1 реагирует слабо (−0.035 $/млн барр., p = 0.02), и только на `API − консенсус`, а не на
   `факт − API`. Для торговой части проекта нужны внутридневные цены или другая постановка.
5. **Уровень спрэда держится за запасы Cushing** (ρ Спирмена −0.83 по уровням), но недельные
   изменения связаны слабо (−0.12).
6. **Ураганы — пример события, которое консенсус недооценивает.** В 14 неделях с ураганом в зоне
   добычи залива средний сюрприз −2.67 млн барр. против +0.45 без штормов (p = 0.012); в месяцы с
   ураганом категории 3–5 добыча в заливе в среднем на 20% ниже медианы, Ida стоила ≈ 26 млн барр.
   Это прямой аргумент за событийные признаки из новостей.
7. **Фундаментальные данные:** 73% дисперсии национального ΔStocks — PADD3; сезонность у нефти слабая
   (5.5% дисперсии), у бензина и дистиллятов сильная (42% и 29%). Из лаговых признаков лучше всего
   работает изменение переработки за 4 недели (corr −0.33 со следующим ΔStocks).
8. **Макро на сюрприз не влияет** (|r| ≤ 0.06), но связано с ценой (breakeven ρ = 0.34). В 2026 г.
   режим другой: WTI до $112.95, F1−F2 до $13.94, знак связи WTI с USD и VIX сменился.

## Проблемы в данных

| Источник | Что не так |
|:--|:--|
| Myfxbook | нет недель отчёта 2022-06-17 и 2023-11-03; 2022-06-29 — первая публикация −0.39 против −2.76 в EIA; консенсус — смесь круглых и усреднённых значений |
| EIA weekly | `crude_production` округлена до 100 тыс. барр./сут (2018-06 – 2024-11); `crude_exports` повторяет прошлое значение 61 неделю в 2015–2016; единицы потоков в parquet не записаны; `approx_crude_balance_mmbbl` без SPR и adjustment — в среднем на 3.55 млн барр./нед ниже факта |
| Barchart | `open_interest` пуст во всех 20 867 строках; объём одинаков у всех 7 nearby; ролл за 2–8 торговых дней до экспирации, поэтому `delta_spread_*` в дни ролла неверны (4.8% дней, 14.7% суммы квадратов изменений); нет −37.63 от 2020-04-20 |
| EIA futures | заканчиваются 2024-04-05; 18 праздничных строк с ценой прошлого дня, 12 пропущенных торговых дней |
| FRED | T10Y2Y и T10YIE — точные разности других рядов; VIX в 32 праздника NYSE с 2022-05; USD broad публикуется раз в неделю и кончается 2026-10-30; `fed_funds_change_5obs_bp` — за 5 календарных дней; CPI и безработица пусты за 2025-10; monthly — пересмотренная версия |
| BSEE | 9 невозможных `history_date` (годы 18…7001), 10 сегментов с `aban_date` 1870 года, `prpsl_con_dt` пуст целиком, 34 числовые колонки строками, 2026-09 добыча неполная, в таблицах есть Тихий океан и Аляска |
| НПЗ EIA | `refinery_key` нестабилен (во всех годах только 63 из 239), нет координат |
| GEM | 69 дублей в `gem_pipeline_ownership_all` (вне США); доли — по путям владения, по проекту в сумме медианно 200%, складывать нельзя; снимок 2026 года, не point-in-time |
| HURDAT2, OSM | best track и текущие снимки — не point-in-time; резервуары OSM в основном промысловые в Канзасе, у Cushing — 2 |

## Для моделирования

- Таргет — по первой публикации факта (Myfxbook); лаговые признаки факта — тоже из неё.
- Включить `API − консенсус` в базовые модели; иначе вклад новостей будет переоценён.
- Изменения спрэда считать same-contract (`curve_clean.parquet`), а не из `delta_spread_*`.
- Потоки EIA той же недели выходят вместе с запасами — только лаг 1 и раньше.
- Метрики устойчивые к хвостам (медианная ошибка, Huber, точность знака) и walk-forward валидация:
  волатильность и информативность консенсуса дрейфуют по годам.
- FRED — на R−2 рабочих дня (VIX на R−1, USD на пятницу недели отчёта); monthly — по дате публикации
  и исходным выпускам. BSEE — с лагом не меньше 2 месяцев.
- Для честного бэктеста заменить best track HURDAT2 оперативными данными NHC.

## Что не проверено

- Время фиксации консенсуса Myfxbook (до или после API) — в данных его нет.
- Точный лаг публикации BSEE и размер пересмотров (нет версий данных).
- Пересмотры FRED monthly: файла с исходными выпусками на этой машине нет.
- 33 дня ролла Barchart вне пересечения с EIA размечены детектором с точностью ≈ 77%; выводы
  event study от этого не меняются.
- Зимние штормы февраля 2021 и декабря 2022 в ноутбуке 02 названы по датам, в данных их нет;
  ураганы Harvey и Ida подтверждены HURDAT2.
